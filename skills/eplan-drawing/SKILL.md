# 从意图到坐标

这一篇只讲两件事：哪些约束是 EPLAN 强加给你的（必须服从），以及哪些东西只是别人那张图的风格（可以不同）。

具体坐标、间距数字、某张已画好的页的参数，**不在这里**，也不要照抄——它们由器件尺寸和你自己声明的布局决定。

## EPLAN 的不变式

这几条不是建议，是渲染规则：

1. **红线自动生成的条件**：两个引脚同轴，且朝向相对。不满足就没有红线，画不出也补不上。
2. **栅格**：元件坐标落在栅格上才对齐得起来。4 mm 是常用值，不是唯一值，但一页之内要统一。
3. **引脚坐标来自符号库**，不来自命名。`symbol_catalog(action="pins")` 是唯一可信来源；符号名里的数字（例如 `Q2`）不保证表示极数。
4. **有些符号不渲染连接点代号**（触点、熔断器组常见）。这类要手写文字补，补之前先把该元件的自动设备标识关掉，否则二者叠在一起。
5. **编辑会触发 EPLAN 的自动符号调整**：它可能换符号变体、删掉它认为悬空的中断点。所以每次编辑之后都要重新出图，建页那一次看着对不算数。

## 节点与页类型

`page_create` 一次摆完整页，字段就这几个（不确定默认值时看这张表，不用读源码）：

| 位置 | 字段 | 说明 |
|---|---|---|
| 顶层 | `type` | `Schematic`（原理图，默认）/ `Overview` / `Panel` / `SingleLine` / `Fluid` |
| 顶层 | `grid` | 吸附栅格 mm，默认 4；被吸附的坐标会在 `snapped` 里报回 |
| `nodes[]` | `symbol` | 必填，符号名（`symbol_catalog` 查过再写） |
| `nodes[]` | `library` / `variant` | 符号库默认 `GB_symbol`；variant 默认 0，换方向是换变体 |
| `nodes[]` | `at` | `[x, y]` 或 `"列/行"` 引用 |
| `nodes[]` | `deviceTag` / `showDeviceTag` | 设备标识文字；后者默认 true |
| `texts[]` | `at` / `text` / `height` | 文字包围盒左下角；字高默认 2.5 mm |

改一个对象不要重建整页：`page_edit` 的 `relocate`（挪）、`relabel`（改设备标识）、`delete_placement`（删）都只动一个对象，按 `objectId` / `deviceTag` / `index` 定位。

参数形状记这三条，别试错：选对象一律 `select{objectId|deviceTag|index}`（`objectId` 来自
`page_inspect(format="structure", view="list")` 的 `rows[].id`）；`relocate` 写 `at:[x,y]` 或
`offset:[dx,dy]`；`relabel` 写 `to:"-K2"`；`draw_graphics` 写 `draw:[{kind:"rect",from:[x,y],to:[x,y]}]`。
写错同义词（`to:[x,y]`、`items`、`type`）会被自动收敛，但**别指望它对**——按上面的写最省事。

**挪对象前先重新取一次 id**：重建过整页之后 id 全变了，拿旧 id 去 relocate 会挪错对象，
比不动更糟。

## 量参考图

要精确位置时不要心算像素。用 `measure`：

1. `calibrate`：图上两个已知点 + 真实毫米 → `pxPerMm`；低于 8 px/mm 会直接告警，那时误差超过半个像素对应的毫米数。
2. `edges`：找竖线/横线，带 `pxPerMm` 与原点时直接给 mm 坐标。
3. `grid`：推主导间距（栅格或器件极距）。

先核对首尾两条线是否和已知尺寸对得上，对不上就是标定选错了，不要继续往下算。

## 从参考图里提取什么

按这个顺序读，前一步没读完不要进下一步：

1. **器件清单**：图上有哪几个器件、各自的标识、型号或参数。
2. **连接关系**：每个器件的引脚接到哪个信号/网络。这一层决定图对不对。
3. **拓扑骨架**：主干是竖列还是横向总线，分支从哪里引。
4. **比例与位置**：只有在用户明确要求「位置也要一样」时才需要。此时先找图上可量化的已知量做标定（例如某个符号的极距），再换算其它位置；不要凭观感。

只做 1–3 时长什么样由你定；做了 4 才需要精确坐标。

**不要照抄另一张页的绝对坐标**：那张页的坐标服务的是它自己的器件组合，搬到新页往往是错位的起点。要复用就把「相对关系」抄过来（哪些元件同 X、哪些同 Y、间隔几个栅格），再按新页的器件重新算。

## 摆放策略

三种骨架，各有适用条件：

- **竖列**：一串元件首尾相连（一个信号从上往下串过多级）。同一列所有元件 X 相同，相邻元件之间留够引脚长度之和，引脚自然同轴相对。适合串联支路。
- **横向总线**：一条等电位线带多个分支。总线 Y 相同，分支点用 T 节点符号；两条线交叉不会自动生成接头，所以不要在总线上用交叉代替分支。
- **网格**：器件之间没有串联关系时（例如并排的若干独立回路），用行列索引排开，靠 layout 管间距。

间距怎么定：**由器件高度和标签宽度决定**，不由记忆里的数字决定。相邻元件至少要放下对方的高度和它的设备标识；拿不准就先排宽松，看图再收。

## 画什么、用什么画

| 目的 | 做法 |
|---|---|
| 导线连接 | **不要画**。摆符号让 EPLAN 自动生成红线 |
| 器件符号 | `page_create` 的 nodes，或 `page_edit(action="insert_symbol")` |
| 设备标识 | 符号自带的（`showDeviceTag` 默认开），或自己写文字但要关掉自带的 |
| 注释、编号、说明 | `page_edit(action="draw_graphics")` 的 text |
| 区域框、表格线 | `page_edit(action="draw_graphics")` 的 rect / line（这些本来就是图形） |
| 黑箱（变频器/PLC 模块） | `page_edit(action="box")`：黄框 + 边缘连接点，一次画完 |

`draw_graphics` 画出来的线是普通图元，颜色和红连接线不是一回事；**图上出现自己画的线去连元件，就说明画法错了**。

## 声明式布局

一页超过四个器件就别手算绝对坐标。给 `layout`，`at` 写引用：

```json
{
  "page": "=EB3+ET1/1",
  "grid": 4,
  "layout": {
    "columns": [60, 100, 140, 180],
    "rows": { "in": 264, "qf": 220, "bus": 180, "fuse": 150 }
  },
  "nodes": [
    { "symbol": "QSF3", "at": "0/qf", "deviceTag": "-QF0" },
    { "symbol": "TLRU", "library": "SPECIAL", "variant": 8, "at": "1/bus" }
  ]
}
```

上面这段只为说明语法，那几个数字没有参考价值，按你自己的器件算。

- 列只能按下标引用（`"0"`、`"2"`），因为列没有名字。
- 行可以命名（`rows` 是对象）或按下标（`rows` 是数组），但**同一页别混用**。
- 引用写错会报 `BAD_LAYOUT` 并列出可用行名，照着改。

## 看相：一页摆得好不好，用数字说话

「画丑了」「太散」「聚拢一点」「线修长一点」——这些话最后都要落到几何上。`validate` 的 `appearance` 一节就是这几个词的量化版本：它把元件按邻近关系分组，量组间空隙、同列相邻间距、四边余量，并给出 `issues`（每条带 `fix`）。

**目标是这四组数字**（不是绝对标准，是一页 A3 横放画 20~40 个器件时通常舒服的量级）：

| 项 | 舒服 | 太小会怎样 | 太大会怎样 |
|---|---|---|---|
| 组间走廊 | 20~40 mm | 标签压字、引脚代号挤成一团 | 页面中间一大片空白，就是「散」 |
| 同列相邻元件间距 | 16~24 mm | 连出来的线是短桩，「线太短」 | 一串元件拉得太开，看串行关系很累 |
| 四边余量差 | < 40 mm | —— | 重心偏了，一边挤一边空 |
| 组内成员 | 相关器件同组 | 同组被拆到两个角落 | 不相关的东西被并成一组 |

`appearance.gaps` 是实测的组间走廊（去重升序），`appearance.pitches.median` 是同列中位间距，`appearance.margins` 是四边余量。

### 一份样板（形状照抄，数字按你的器件重算）

一页 A3 横放、三个驱动箱 + 一条主回路的真实摆法：

```json
{
  "page": "=JQR2623/7",
  "grid": 4,
  "layout": {
    "columns": [48, 96, 148, 200, 252, 304],
    "rows": { "top": 268, "bus": 232, "qf": 196, "km": 160, "drive": 120, "pe": 56 }
  },
  "nodes": [
    { "symbol": "FA3",  "library": "GB_symbol", "variant": 0, "at": "0/top",  "deviceTag": "-F14" },
    { "symbol": "QSF3", "library": "GB_symbol", "variant": 0, "at": "1/bus",  "deviceTag": "-QF14" },
    { "symbol": "FA3",  "library": "GB_symbol", "variant": 0, "at": "2/km",   "deviceTag": "-K36" },
    { "symbol": "SON",  "library": "GB_symbol", "variant": 0, "at": "3/qf",   "deviceTag": "-S1" },
    { "symbol": "LSW1", "library": "GB_symbol", "variant": 0, "at": "4/qf",   "deviceTag": "-S2" },
    { "symbol": "BP",   "library": "SPECIAL",   "variant": 1, "at": "9/pe",   "deviceTag": "-X1" }
  ],
  "texts": [
    { "at": [48, 276], "text": "主回路", "height": 2.5 }
  ]
}
```

这份样板之所以「看着不丑」，靠的是四条相对关系，而不是那几个数字：

1. **同列的元件 X 完全相同**（`at` 用同一个列名）——上下引脚自然同轴，红线自动出来，不用画。
2. **同列相邻行至少隔一个器件高度 + 12 mm**——连出来的线有长度，不是短桩。
3. **每列的 `deviceTag` 朝外侧**——内侧留给走线和引脚代号，标签永远不压在线上。
4. **组与组之间空出一条 24~32 mm 的走廊**——`appearance.gaps` 落在这个区间就不会被说「散」。

### 自检 8 条（出图前逐条对照，不合格就改，别等用户说）

1. 有没有哪个组只有 1 个器件，却离最近的组超过 60 mm？（`groups_scattered`）
2. 两个组的走廊是不是小于 4 mm、标签已经开始打架？（`group_crowded`）
3. 同列中位间距 < 6 mm？（`short_wires` —— 这就是「线修长一点」的由来）
4. 四边余量最大与最小差超过 60 mm？（`uneven_margins`）
5. 同一功能的器件（一个驱动的进线开关 + 接触器 + 变频器）在同一组里吗？
6. 设备标识是不是统一朝外？有没有两个标识挤在同一侧？
7. 主回路的竖列和二次回路的横排是不是各走各的，没有互相穿插？
8. 页面上有没有「画了但没接线」的孤立符号？有就删掉，别留着凑数。

### 用户原话 → 改法

| 用户说 | 大概率问题 | 怎么改 |
|---|---|---|
| 画丑了 / 太乱 | 组间既有大空隙又有贴边的 | 先按 `appearance.issues` 修 1~3 条最大的，整页重画是最后手段 |
| 聚拢一点 | `groups_scattered` | 外围组朝主轴收 20~40 mm，组内不动 |
| 线修长一点 | `short_wires` | 同列行间距各加 8~12 mm（改 `layout.rows` 一处即可） |
| 散开了 / 空太多 | `groups_scattered` + 余量偏一侧 | 收组间走廊到 24~32 mm，再整体平移居中 |
| 太挤 / 看不清 | `group_crowded` + `label_overlap` | 扩走廊到 12 mm 以上，标识朝外 |

**先修数字，再谈重画**：改 `layout` 的行列值是一处改动，整页删了重画要重算所有相对关系，还可能把已经对齐的引脚弄丢。

## 常见画法错误与后果

| 错误 | 后果 |
|---|---|
| 用 `draw_graphics` 画线去连元件 | 线不参与连接，EPLAN 认为这几个引脚是断的 |
| 自己写设备标识又没关自动标识 | 图上出现两个同样的标识 |
| 文字栅格和元件栅格相同 | 文字被吸附到元件上，渲染时压字（`label_overlap`） |
| 元件不在同一 X 却指望出竖线 | 引脚不同轴，没有红线 |
| 改了布局就删页重建 | 重建会丢掉页上原有的一切；挪一个对象用 `relocate`，改标识用 `relabel`，删一个用 `delete_placement` |
| 建页完就宣布完成 | 自动符号调整可能已经改过东西，没重渲等于没验 |
| 手算像素换毫米 | 换错后所有坐标一起错；用 `measure calibrate` + `edges`，标定完先核对首尾两条线 |
