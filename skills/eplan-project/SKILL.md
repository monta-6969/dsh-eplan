# 新建一个大项目

「大项目」不是「一页画更多东西」，而是**先有页清单，再逐页闭环**。没有清单就动手，
画到第 4 页才发现第 1 页的器件标识规则不对，只能全删。

## 流程

1. **确认范围**：项目名、图幅（A3/A4）、页数、每页主题、参考图/视频在哪。
   不清楚就问；不要用默认值硬猜「2026」这种有歧义的名字。
2. **建项目**：`workspace({action:"create_project", name, template, dryRun:true})` 先看路径，
   再正式建。项目默认落在 EPLAN 默认目录，不要自己拼路径。
3. **写页清单**：每页一行：页名、主题、参考图、状态（todo / drawing / review / done）。
   清单落在项目台账（`workspace` 的 plan_* 动作，见下），不要只写在对话里。
4. **逐页闭环**：认领一页 → 画 → `validate` → 渲染 → 审查子代理 → 修 → `present` → 标记 done。
   一页没闭环之前不要开下一页。
5. **汇总呈现**：全部 done 后 `present` 第一页，并列出每页的页名/符号数/validate 结论。

## 台账（多实例并行）

- 位置：`%LOCALAPPDATA%\eplan-mcp\projects\<project>\plan.jsonl`（页清单）与 `lock.json`（页锁）。
- 写一页之前先 `claim` 那页；同一页被别的会话锁住时，等或换页，不要硬写。
- EPLAN 桥本身有跨进程 mutex，调用会排队；台账解决的是「谁负责哪页」，不是并发写。
- 两个模式不要同时驱动 EPLAN；一次只让一个会话动一个项目。

## 页号与命名

- 页名形如 `=VFD/1`、`=MI/12`：`=` 后是高层功能，`/` 后是页号。
- 新建页前先 `workspace({action:"list_pages"})` 看已占用的页号；
  `PAGE_EXISTS` 会给出可用页号，按它来，不要从 1 开始猜。
- 用户说「新建为 2026」先确认是页号 2026 还是项目名 2026。

## 拆分建议

- 一页一个功能块：进线/电源、控制回路、输出/端子、说明页。
- 跨页连接用中断点（BP）；同一电位名在两页出现，EPLAN 自动交叉引用。
- 器件标识跨页保持一致；多部件设备共用同一个 `-X1` 是正常的。
